## Exact addition from the photographed tables

The app previously displayed the paternal-brother + paternal-sister 2:1 rule in the guide but did not calculate it. It now calculates that exact table rule when the selected family contains the paternal brother and paternal sister **without** a descendant, father, paternal grandfather, or full sibling. Any combination outside those complete, table-readable conditions is retained as a specific qualified-review case rather than being treated as the same automatic path.
