# Family Selector Visual Validation

The first desktop browser capture showed that two-column relationship cards crowded longer Tamil labels once the desktop helper panel was visible. The layout was changed to use one relationship card per row until extra-wide screens.

The first mobile browser capture showed that the large sticky help card could overlap family controls. The helper is therefore kept sticky only on wide screens. On mobile it remains a visible in-flow help card after the family choices, preserving the emoji guide without obscuring any control.

The desktop and mobile browser journey both reached the family-selection screen and expanded advanced relationships successfully. Calculation and browser-storage regression tests also passed.
